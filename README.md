INSTRUCTIONS
1. Create a new database in pgAdmin named "Student"
2. Right click the database, select Query Tool, press Open File, then choose create_student_database.sql
3. Run the query to create the students table and fill it with the provided data
4. Open DatabaseOperations.java and replace the values for the user and password variables with your own database information
5. Run the program and follow the prompts
